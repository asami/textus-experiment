# Textus Experiment User Guide

1. Select one immutable Textus Corpus revision.
2. Define an experiment against that revision.
3. Define at least one treatment arm with an execution-plan reference.
4. Activate the definition, then start a run.
5. Execute each selected corpus case through the application acceptance
   operation and record the resulting evidence reference.
6. Complete the run and derive its aggregate summary.

Definitions, arms, runs, and observations are immutable after their lifecycle
transition. Exact command retries are idempotent; replacement content is
rejected.
